# 🎵 Music Player WEB

ブラウザだけで動く、高機能・高性能なウェブ音楽プレイヤーです。  
A high-quality, feature-rich music player that runs entirely in your browser — no installation, no backend required.

---

## ✨ 主な機能 / Features

| 機能 | 説明 |
|------|------|
| 🎵 マルチファイル再生 | MP3 / AAC / FLAC / OGG / WAV など主要な音声フォーマットに対応 |
| 📋 プレイリスト管理 | 複数ファイルをドラッグ&ドロップで追加・削除・並べ替え |
| ☁️ Google Drive インポート | 共有URL（公開ファイル）から直接取り込み |
| 🔀 シャッフル | ランダム再生（履歴ありの戻る機能付き） |
| 🔁 リピート | オフ / 全曲リピート / 1曲リピートを切り替え |
| ⏩ 再生速度 | 0.5× 〜 2× の 6 段階 |
| 🔊 音量コントロール | スライダー + ミュートボタン |
| 🎚 10バンド イコライザー | 32Hz 〜 16kHz の各帯域を ±12dB で調整（Web Audio API） |
| 📊 ビジュアライザー | リアルタイム周波数スペクトルアナライザー（Canvas） |
| 🏷 メタデータ表示 | ID3v2 タグからタイトル・アーティスト・アルバム・カバーアートを自動取得 |
| ⌨ キーボードショートカット | スペース / 矢印キー / M / S / R / E |
| 💾 設定の永続化 | 音量・速度・EQ・シャッフル・リピートを `localStorage` に保存 |
| 📱 レスポンシブ | スマートフォン〜デスクトップまで対応 |

## 🚀 使い方 / How to Use

1. `index.html` をブラウザで開く（ダブルクリックするだけで OK）
2. 左上の ☰ ボタンでプレイリストを開く
3. 「＋ ファイルを追加」または画面にドラッグ&ドロップで音楽ファイルを追加
4. 曲をクリック、または ▶ ボタンで再生開始

### Google Drive からインポート

1. サイドバーの **Google Driveからインポート** をクリック  
2. Google Drive の共有URLを貼り付け  
3. 公開設定された音声ファイルを直接プレイリストへ追加

> Google Drive 側の共有設定が「リンクを知っている全員」に公開されている必要があります。

> **Note**: ローカルファイルを直接開く場合は、ブラウザのセキュリティ制限により  
> Web Audio API が動作しないことがあります。その場合は簡易 HTTP サーバーを使ってください。
> ```bash
> # Python 3 の場合
> python -m http.server 8080
> # その後 http://localhost:8080 を開く
> ```

## ⌨ キーボードショートカット / Keyboard Shortcuts

| キー | 動作 |
|------|------|
| `Space` | 再生 / 一時停止 |
| `←` | 前の曲（または先頭に戻る） |
| `→` | 次の曲 |
| `↑` | 音量 +5% |
| `↓` | 音量 -5% |
| `M` | ミュート切替 |
| `S` | シャッフル切替 |
| `R` | リピートモード切替 |
| `E` | イコライザーパネル開閉 |

## 🛠 技術スタック / Tech Stack

- **HTML5** — セマンティックマークアップ
- **CSS3** — グラスモーフィズム・ダークテーマ・CSS アニメーション
- **Vanilla JavaScript (ES2020)** — ゼロ依存
- **Web Audio API** — EQ フィルターチェーン・オーディオビジュアライザー
- **File API** — ローカルファイルの読み込み・ID3v2 メタデータ解析
- **Canvas API** — リアルタイム周波数スペクトル描画
- **localStorage** — ユーザー設定の永続化
